# 结果展示与通用回复模板

按当前状态读取对应模板，不把整份模板库输出给用户。模板中的尖括号为填槽说明，只填真实回执或用户已明确的信息；未知必需项写“未返回/暂未确认”，无关可选项省略。正常单项结果一两句即可，不强制做卡片。

## 选择模板

| 场景/状态 | 唯一模板来源 |
| --- | --- |
| 需要扫码授权、授权完成、退出账号 | [auth.md](auth.md)，不追加通用总结 |
| 单动作/组合写入待确认 | [confirmation.md](confirmation.md)，不按每一步重复索要确认 |
| 单项成功 | T1 |
| 查询列表、详情、统计 | T2 |
| 空结果 | T3 |
| 批量或组合任务全部成功/部分完成 | T4 |
| 异步处理中、结果未确认 | T5 |
| 失败、拒绝、能力不支持 | T6；原因解释参照[errors.md](errors.md) |
| 候选不唯一、缺少必要信息 | T7 |
| 生成分享链接 | T8 |

“卡片”指聊天中的简短文字和必要列表，不自建HTML、网页、SVG或可视化组件。图片、附件遵循当前宿主能力。不要把CLI JSON、代码块、状态枚举、内部引用、日志、票据有效期翻译成用户回复；排障标识仅用户索要时给。

## T1 单项成功

已<完成动作>：<真实名称>。
位置：<真实云端路径或本地位置>。

第二行仅在用户需要或该动作必须说明目标时显示。文件大小只在上传/下载等必要场景或用户询问时提供。自动改名时补一句“已自动改名为<实际名称>，保留了原有同名文件”，不要继续使用计划中的旧名称。订阅成功补一句“订阅不会自动转存”；不附整套能力介绍，不每次都问“还需要什么”。

## T2 查询结果

<范围>，本次返回<N>项：

1. <名称> · <本次需要的属性>
2. <名称> · <本次需要的属性>

展示本次返回的全部项目（条数＝回执 `page.returned`，不超过 `pageSize`，默认一页 10 条）：**不设"先展示 N 项"的二次上限，也不罗列或预告未展示项**。没有可靠total不说“共有”。用户要更多就按原请求允许的分页再取一页（一次查询对应一次结果输出，不逐页索要确认）。

- 本页满页且仍有游标（`page.complete=false`）：必要时提示"回复'继续'可查看后续结果"。
- 本页未满，或回执无游标（取尽）：本次结果已取完，不再提示继续翻页，也不说"未查全"。
- 其他域（如动态接口）出现 `complete=false` 且无游标时：说"当前结果可能不完整"，不承诺能继续翻页。
- complete=true：只表示本次查询范围已取尽，不扩展为整个账号历史。
- 详情不强加数量/是否查全的汇总，直接输出用户问的名称、大小、时间或位置。
- 统计写明时间段、指标及去重口径，未知数不填0；**统计被上限截断（如月度统计触及 500 页，`complete=false`）时必须标注"仅统计已获取记录"的口径，不得当作全量**。

## T3 空结果

在<实际查询范围>内，没有找到<用户要找的对象>。

仅在需要时补一个建议，如“可以补充名称或调整时间范围”。不要擅自扩大范围，**也不要在同一轮改用默认范围或其它范围再查一次**：空结果本轮只问不查，扩大须经用户确认；范围句必须写明**本次实际生效的范围**（用户指定了时间就写用户指定的范围，不得改写成默认范围）。当前页为空但有后续游标，不能说整个范围没有结果；应说明本页无匹配项并按原请求处理后续页。部分来源查不到记录，不等于整个账号没有记录。

## T4 批量与组合任务

全部完成时：
已完成<N>项操作。
- <动作和对象>：<实际结果/目标>

部分完成时：
已完成<N>项，<M>项未完成。
- 已完成：<动作、对象、实际结果>
- 失败：<动作、对象、已证实原因>
- 结果未确认：<动作和对象>
- 尚未执行：<后续步骤>

只展示确实存在的类别。数量来自回执与步骤明细，不能把未执行、处理中或未知归为失败，也不能把子步骤数量当文件数量。失败后停止的编排不能说“剩余都失败”。已成功项不重做；用户要求处理剩余项时，仅针对可确认未执行或失败且允许重试的项重新规划。未知结果先核实，不能自动重新提交。

## T5 处理中与结果未知

明确处理中：<任务>仍在处理中，暂未确认完成。
结果未知：暂时无法确认<任务>的最终结果。

已确认的阶段或部分结果可补一句，不编造速度、百分比或剩余时间。不把已受理说成已完成；不把超时一律说成失败。有合法任务查询入口时才提示可继续查状态，不能承诺后台自动跟踪。

## T6 失败、拒绝、能力限制

未能完成<动作>：<经证实的业务原因>。
<一个当前确实可执行的建议，仅在必要时追加>。

写入是否发生按证据说明；无法确认就用T5，不说“云盘没有任何变化”。不根据“参数不合法”猜测文件损坏、文件名违规、授权失效或网络问题。只给该接口支持的选项：例如建目录同名可换名或选已有目录，不能随意建议覆盖/跳过。纯确认或授权状态不套失败模板。

## T7 需要用户补充

找到多个<对象>，请选一个：
1. <名称> · <可区分的路径/时间/脱敏标识>
2. <名称> · <可区分的路径/时间/脱敏标识>

缺必需信息时只问一件事，例如“请告诉我要上传的文件路径”。已有合法默认值不逐项追问，不展示真实内部ID。

## T8 分享链接

已生成<对象名称>的分享链接：真实链接。
提取码：<已返回且使用该链接需要的提取码>。
有效期：<实际已返回或冻结计划明确的有效期>。

提取码、有效期不适用或未返回时省略，不编造。仅链接生成不能说“已发送给某人”；公开范围在确认卡中提前说明。
