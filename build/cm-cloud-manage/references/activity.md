# activity 动态、阅读与统计

> 领域说明：仅在 `SKILL.md` 已把动作路由到 `activity` 后加载。执行前先取 `cmcloud help --topic activity --format json` 与 `cmcloud schema --command-id <command-id> --format json`。**参数类型、必填、枚举全集、上限与成功判定一律以 CLI schema 为准**；本文件只给命令索引、参数名索引和编排规则，不内联 schema、下游字段名或成功码。

## 何时触发

> 以下为**触发线索**；线索需能绑定明确对象（时间、类型、文件名关键词，或上一轮 CLI 回执的候选）。仅时间词见文末规则。

- **查询浏览/听歌动态 `cmcloud activity list --eventKinds browse`**：看过什么、浏览过什么、最近看了什么、听了什么歌、播放记录（宾语＝时间/类型/文件名）。
- **查询上传动态 `cmcloud activity list --eventKinds upload`**：上传了什么、传了哪些、上传记录、今天传的照片、最近导入的视频（宾语＝时间/类型/文件名）。
- **查询分享转存动态 `cmcloud activity list --eventKinds share-save`**：从分享转存的、分享转存、外链转存记录。 
- **查询圈子/群组/家庭云转存动态 `cmcloud activity list --eventKinds group-save`**：圈子转存、群组转存、共享群转存、家庭云转存。
- **查询发现转存动态 `cmcloud activity list --eventKinds discover-save`**：发现转存、从发现页转存。
- **查询全部转存（不限定来源） `cmcloud activity list --eventKinds all-save`**：所有转存、全部转存、不限来源的转存。
- **阅读/听书记录 `cmcloud activity reading`**：最近在读什么书、最近读了什么书、阅读记录、听书、听了什么书、在听什么书、听书记录（**无关键词参数**，不能按书名筛选；**也无时间入参**，不能按时间筛选；可按内容类型查一类或多类，见下文参数）。
- **月度上传事件统计 `cmcloud activity stats`**：按月查看完整范围内的上传事件数（宾语＝时间范围）；此命令不筛选图片，不能用于回答“每个月上传了多少张照片”。

单独的时间词（今天/最近）也进入本域，但须先轻量询问"想看上传、浏览、转存还是阅读记录？"，**不自行选择事件类型**。

## 何时不触发

- `继续播放`/`播放这首歌`、`每月挑选质量最好的 2 张` → 本期不支持，不调用
- `最近修改的文件`、`最近的 PDF`、`去年旅行照片`、`找猫的照片` → `cmcloud files search`
- `最近创建的相册`、`旅行影集` → `album`
- `上个月照片按月成册` → 本期不支持，不调用
- `每个月上传了多少张照片`、`这个月传了几张图` → 当前统计命令不筛选图片，不能给出准确图片数；可说明仅支持按月统计观察到的上传事件
- 写入向同词：`上传这个文件` → `cmcloud files upload`；`转存这个外链` → `cmcloud share save`；`分享这个报告` → `cmcloud share create`
- `听了什么歌`／播放记录／歌曲 → 不是阅读记录，只走 `cmcloud activity list --eventKinds browse`；`听了什么书`／听书／在听什么书 → 属阅读记录，走 `cmcloud activity reading`（`contentType=5`）。分界在**宾语是"歌"还是"书"**，不能只看"听"这个动词；宾语不明确（如只说"最近听了什么"）时先轻量追问"听的是歌还是书"，不自行选一路。
- 无云盘上下文的时间词（`今天有什么`、`今天北京天气`）→ 不触发

## 用户话术到结构化参数

> 本节说明各场景下**每个参数怎么选**；**参数类型、必填、上限、默认值与枚举全集以 `cmcloud schema` 为准**。
> 本领域命令：`cmcloud activity list`、`cmcloud activity reading`、`cmcloud activity stats`；`cmcloud activity list` 由 `--eventKinds` 路由（**必填单值**），取值全集 `browse`/`upload`/`share-save`/`group-save`/`discover-save`/`all-save`，各场景块只固定自己的值；参数与枚举由 `cmcloud help --topic activity`、`cmcloud schema --command-id <command-id>` 下发。

**时间词 → 显式 `from`/`to`（半开区间）**

> 用户给出时间词（今天、昨天、这周、上周、最近 N 天、本月、上个月…）时**必须显式传 `from`/`to`**，按用户口径换算成半开区间；省略参数不等于“与用户口径一致”，而是把范围放大到默认窗（见下文读流程）。区间含 `from`、不含 `to`。时间词表外或边界无法确定时**先澄清**，不擅自换算，**也不退化为默认窗**；只有用户**完全没提时间**时才允许省略。

**浏览/播放动态 `cmcloud activity list --eventKinds browse`**

- `--eventKinds`：固定 `browse`（查看/浏览/听歌）。
- `from`/`to`：时间词规范化为半开区间，"最近"默认 7 天；**成对**使用。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4。
- `pageSize`/`cursor`：`pageSize` 默认 10，用户指定前 N 条时可调整；`cursor` 在用户说"继续/下一页"时取上一轮回执的游标。

**上传动态 `cmcloud activity list --eventKinds upload`**

- `--eventKinds`：固定 `upload`。
- `uploadKind`：未限定来源的问法（"上传了/传了哪些/上传记录/今天传的照片"）**不传**该字段——只有省略才合并普通上传与美图上传两类；"美图上传的" → `beauty`；"只要普通上传、不含美图" → `normal`（取值 `normal`/`beauty`；合并口径以 `cmcloud schema --command-id activity.list` 的字段说明为准）。
- `from`/`to`：时间词规范化为半开区间；成对使用。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4。
- `pageSize`/`cursor`：`pageSize` 默认 10，用户指定前 N 条时可调整；`cursor` 在用户说"继续/下一页"时取上一轮回执的游标。

**分享转存动态 `cmcloud activity list --eventKinds share-save`**

- `--eventKinds`：固定 `share-save`（从分享/外链转存的动态）。
- `from`/`to`：时间词规范化为半开区间；成对使用。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4。
- `pageSize`/`cursor`：`pageSize` 默认 10，用户指定前 N 条时可调整；`cursor` 在用户说"继续/下一页"时取上一轮回执的游标。

**圈子/群组/家庭云转存 `cmcloud activity list --eventKinds group-save`**

- `--eventKinds`：固定 `group-save`。
- `sourceKind`："圈子" / "群组/共享群" / "家庭云" → 对应来源（取值见 schema）。
- `from`/`to`：时间词规范化为半开区间；成对使用。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4。
- `pageSize`/`cursor`：`pageSize` 默认 10，用户指定前 N 条时可调整；`cursor` 在用户说"继续/下一页"时取上一轮回执的游标。

**发现转存动态 `cmcloud activity list --eventKinds discover-save`**

- `--eventKinds`：固定 `discover-save`（从发现页转存的动态）。
- `from`/`to`：时间词规范化为半开区间；成对使用。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4。
- `pageSize`/`cursor`：`pageSize` 默认 10，用户指定前 N 条时可调整；`cursor` 在用户说"继续/下一页"时取上一轮回执的游标。

**不限来源转存 `cmcloud activity list --eventKinds all-save`**

- `--eventKinds`：固定 `all-save`（汇总分享、圈子/群组/家庭云、发现全部受支持来源的转存动态）。
- `from`/`to`：时间词规范化为半开区间；成对使用；该条件同时作用于三类来源。
- `keyword`：用户给出的名称/词；仅按文件名包含匹配；三类来源共用。
- `contentType`：图片＝1、音频＝2、视频＝3、文档/压缩包及其他文件＝4；三类来源共用。
- 采集保护上限由 CLI 内部固定，**不作为触发参数**；达到上限时不得声称查全。

**阅读/听书记录 `cmcloud activity reading`**

- `contentType`：内容类型**（单选）**，取值 `1`＝咪咕云阅读、`5`＝咪咕云听书、`20`＝内容平台入库的版权书籍（米讯书籍）、`100`＝云盘书籍；"看书/阅读记录" → `1`，"听书/听了什么书" → `5`；不得使用枚举以外的整数。
- `allowContentTypeList`：内容类型**（多选）**，"看书和听书都要" → `[1,5]`，"连版权书籍一起" → `[1,5,20]`，用户明确要"全部 / 所有阅读记录" → `[1,5,20,100]`；数组内不得重复、不得含枚举外取值；传空数组 `[]` 表示**不限类型**（与省略同义）。
- 上述两个类型字段**互斥**，同时提交会被本地直接拒绝（`INVALID_ARGUMENT`），须二选一。
- 不限类型时（两个字段都省略，或 `allowContentTypeList` 传 `[]`），契约口径是"**筛选所有阅读记录**"（含 `20` 版权书籍）；CLI 统一显式下发 `allowContentTypeList=[1,5,20,100]`**，以兑现"所有"的契约语义，不依赖平台那个与契约不符的默认。用户显式传了非空类型时按用户传，不做合并。
- **查询范围由平台固定**：只覆盖**最近 6 个月内**打开过的电子书，**一次返回全部（最多 30 条）**、按 `updatedAt` 降序，咪咕文件与云盘文件混排；接口**没有时间入参、没有分页游标、没有总数**——不接受按时间收窄或扩大范围，也不存在"往前翻更早历史"的入口。

**月度上传事件统计 `cmcloud activity stats`**

- `from`/`to`：统计范围（**必填**）。
- `timezone`：可选，CLI 默认 `Asia/Shanghai`。当前实现仅回显此值，没有按指定时区重算月份；用户要求其他时区的精确月统计时，不能声称已满足。
- `uploadKinds`：普通上传 → `normal`；美图上传 → `beauty`；未限定来源时省略，纳入两类上传事件。该字段只区分上传来源，不筛选图片类型。
- 统计会持续翻页直到上游明确不再下发游标，但**一次统计命令内全部来源分支共享 500 页硬性上限**；达到上限即停止取页并把结果标记为不完整（不声称查全），游标重复或格式非法时明确失败，绝不静默截断为部分统计。

时间词与操作词（看、浏览、上传、转存、听、阅读）组合时进入对应事件类型；仅有时间词时，先轻量澄清事件类型，不自行选择。

## 读流程

- **动态（`cmcloud activity list`）**：按 `--eventKinds` 选定唯一事件类型后执行。底层使用最新 V3 路径；`keyword` 未指定时传空字符串，`pageSize` 默认 10。时间标准化为半开区间；支持的多类型查询使用 `dynamicTypes`。上传事件只查普通上传与美图上传：未限定来源时必须**省略** `uploadKind`，不得用 `normal` 代替"上传记录"，也不得对用户表述为"全部上传"。动态接口本身不返回名称：CLI 用每条动态的 `contentId` 调个人云文件批量详情补齐 `name`，补名失败或未命中的条目才按"名称未返回"输出；`type`、`category` 与 `dynamicTime` 正常输出，`dynamicTime` 同时归一化为 `occurredAt`；`contentId`、`parentFileId` 与批次 ID 仅签发用途受限的受控引用，不暴露真实 ID，也不得把动态 ID 当作 `fileRef`。**仅当用户完全未提及时间**时才允许省略 `from`/`to` 并使用默认查询窗**最近 30 天**（`CMCLOUD_ACTIVITY_WINDOW_DAYS` 可调）；用户给出任何时间词（今天／昨天／这周／上周／最近 N 天／本月／上个月…）时**必须按上文“时间词 → 显式 `from`/`to`”显式传参**——省略参数不等于“与用户口径一致”，而是把范围放大到默认窗。`page.complete=true` 只表示**该时间窗内**已取尽（上游不再下发后续游标且本轮无数据），**不代表更早历史**；仍有后续游标时 `hasMore=true、complete=false`；本轮有数据但无后续游标时 `hasMore=null、complete=false`（无法证明取尽）。上游明确返回可信 `total` 时可以展示总记录数，但不得把当前页条数冒充总量。查询跨度超过 30 天时先说明范围与查询成本。
- **不限来源转存（`--eventKinds all-save`）**：对分享/圈子/发现三类转存分别分页后合并去重；任一类未终止或来源不完整时 `page.complete=false`，不得称"全部转存"。
- **阅读/听书（`cmcloud activity reading`）**：内容类型由 `contentType`（单选）或 `allowContentTypeList`（多选）指定，二者互斥；**不限类型时（两个都不传，或 `allowContentTypeList` 传 `[]`）CLI 统一显式下发全量 `[1,5,20,100]`**（见上文参数说明）。平台只覆盖**最近 6 个月内**打开过的电子书，**一次返回全部（最多 30 条）**、按 `updatedAt` 降序，咪咕文件与云盘文件混排；**没有时间入参、没有分页游标、没有总数**，因此既不能按时间收窄范围，也没有"往前翻更早历史"的入口。成功判定兼容契约 `code=0` 与现网 `success=true`+`code="0000"`。返回条数达到 30 条时可能已被平台截断，不得声称"这就是全部阅读记录"。
- **月度统计（`cmcloud activity stats`）**：按 `uploadKinds` 指定的来源分支分别翻页采集至上游明确结束（全部分支共享 500 页上限，见上文）→ 按稳定标识去重 → 按上游时间字符串所属月份分组；当前不筛选图片类型，也不按 `timezone` 转换月份。成功回执的 `complete=true`、`basis=full-window`、`truncated=false` 表示该时间窗口已取尽；达到 500 页上限时 `complete=false`、`basis=observed-only`、`truncated=true`，相关分支计入 `truncatedBranches` 且 `branchStopped=page-cap`；若游标重复或非法则命令明确失败，不返回部分观察值。
- **动态结果的大小/位置**：不在本域补查；需要时改用 `cmcloud files info`（见 `files.md`），且仅在"动态引用 → 真实文件 ID"映射已确认时执行，否则标注字段不可得。**不得用名称或目录文本推断路径或大小。**

## 领域异常和恢复

| 异常 | 处理 |
| :-- | :-- |
| 分页未拉全、来源部分失败或游标未终止 | 输出 `page.complete=false`，不报确定总量；说明已覆盖来源 |
| 月度统计游标重复或非法 | 明确失败并请维护方排查；不得返回部分统计或宣称已取尽 |
| 阅读记录 `updatedAt` 缺失或不可解析 | 仍按上游返回顺序展示，不猜测时间、不据此重排，也不声称"最近" |
| 动态缺少文件大小/位置 | 标注"暂不可得"；仅在映射已确认时经 `cmcloud files info` 补查，不按名称推断 |
| 跨来源结果可能重复或漏项 | 按时间 + 稳定 ID 去重；无法证明完整时不称全量 |
| 来源无法区分（如转存的分享/圈子/家庭云归属） | 只返回可证明的来源，不把全部结果归为某一来源 |
| 查不到 | ① 只用**用户请求的那个范围**如实说明未找到（不得把默认窗的结果说成用户范围的结果）；② 询问是否扩大，并给出**建议的更大范围**（如“要不要看最近 30 天？”）；③ **本轮到此结束**——用户确认前**不得**再发第二次查询，确认后的新查询必须**显式带新的 `from`/`to`** 并在回复中写明新范围 |
| 阅读记录被要求按时间筛选（如"上周读的书""去年在读什么"） | 该接口**没有时间入参**，如实说明只能按平台固定范围（最近 6 个月内）返回，不假装按时间筛过 |
| 上游响应缺少名称 | 先按 `contentId` 批量补名；补名失败或未命中时才保留时间、类型与受控动态引用并标注“名称未返回”；不猜测文件名，也不暂停整个查询能力 |
| 上游在鉴权/网关层被拒（响应无 `resultCode`，改用公共包络） | 按真实业务码与原因如实外发（如“有其他授权在处理中”）；此类拒绝本次未产生查询副作用，按上游码说明是否可重试；**不得**说成“接口坏了/契约不符”，也不得据此声称已查全 |
| 仅时间词、未指定事件类型 | 先轻量澄清（上传/浏览/转存/阅读），不自行选择 |

## 输出追加项

> 通用骨架见 [结果展示](output.md)；本节只列 activity 域必须额外出现的信息。

- **动态查询**：汇总句写明事件类型与条数，并**必须写明本次实际生效的查询范围**：用户指定了时间时写**用户指定的范围**（如“本周”），只有用户完全未指定时间时才写"最近 30 天"，同时提示**其它时间范围的记录需要另行发起一次查询**；本次为空时只输出“该范围内未找到 + 是否扩大范围”，**本轮到此结束**——用户确认前**不得**改用默认窗或其它范围再查一次；`page.complete=true` 不等于"全部历史都已查全"。明细逐行 `- <时间>（<名称>，<来源>）`。补名后仍无名称的条目，保留其他可信字段并明确标注“名称未返回”；父目录仅返回受控引用，不等于可展示路径；大小、完整位置仍须在映射已确认并经 `files.info` 补查后展示。
- **月度统计**：使用回执的 `months`、`observedEvents`、`observedUnique`、`complete` 与 `basis`；`complete=true` 且 `basis=full-window` 时，汇总句直接给出指定时间窗口内的上传事件总数及去重数；不追加图片类型、观察口径等解释性文案。`complete=false`（`truncated=true`）时必须标注口径，说明"本次达到 500 页查询上限，仅统计已获取的上传记录，尚未覆盖该时间范围的全部记录"，**不得输出全量总数、不得把未开始分支显示为 0 条已查全**；正常完整统计不追加此类提示。命令失败时不展示部分统计。
- **阅读记录**：标口径与条数（"最近 6 个月内 · 本次取到 N 条"），并说明本次覆盖的内容类型。返回条数少于 30 条时可说明"6 个月内没有更多"；**正好 30 条时只能说"平台最多返回 30 条"**，不得声称覆盖 6 个月之前，也不得把"N 条"说成"全部阅读记录"。
- 按 `page.hasMore`/`page.complete` 如实收尾（语气见 [结果展示](output.md)，可用自然说法）：还有后续游标时说"还有更多，要接着往下看吗"；`complete=false` 但没有后续游标时只说"可能还有没列出的"，**不承诺**能继续翻；`complete=true`（含翻到空页后判定取尽）时说"以上就是最近 30 天（或你指定的时间段）的记录"并提示更早记录需另行发起，**不得**再说"未查全/还有更多"。
