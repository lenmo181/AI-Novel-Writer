## 中文

修复：更新弹窗把 GitHub 返回的 HTML 更新说明显示成源码（electron-updater 走 GitHub 摘要流拿到的是渲染后的 HTML，弹窗此前只清理 markdown）。现在 markdown 与 HTML 两种来源都转成可读纯文本，弹窗正常展示每个版本的更新内容。

## English

Fixed: the update dialog displayed GitHub's HTML release notes as raw source (electron-updater's GitHub feed returns rendered HTML; the dialog only cleaned markdown). Both markdown and HTML sources are now converted to readable plain text, so the dialog shows each version's notes properly.

Windows installers are unsigned. Mac installers are ad-hoc signed, with no Developer ID signature or Apple notarization.
