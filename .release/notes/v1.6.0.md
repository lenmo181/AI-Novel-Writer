# 1.6.0

## 中文

1.6.0 是一次产品级升级：全局导航与创作流程重构、全文审稿中心、油画风主题、启动动画，以及一整轮打开与生成性能修复。

新增：

- 全局导航重构：左栏主导航聚合书房、创作工作区（设定/架构/蓝图/正文）、全文审稿与 AI 运行，底部直达「模型」与「提示词」；Ctrl+K 命令面板收录全部新入口。
- 全文审稿中心：全书视角的问题看板，聚合每章最新一次审稿，按严重程度与处理状态筛选，逐条一键跳回对应章节；书房首页同时显示审稿待办。
- 创作流程扩为六步：设定 → 架构 → 蓝图 → 写作 → 审校 → 定稿与导出。审校步显示已审章数与待处理问题数，定稿步显示定稿进度并直达导出。
- 应用启动动画：印章铺纸开场、一次性入场过渡到书房；开启「减少动态效果」时自动跳过。
- 书房工作状态卡：审稿待办与进行中 AI 任务，仅在有真实待办时出现。
- 运行侧页「可恢复的内容」默认收起为一行计数，按作品记忆展开状态。

改进：

- 油画风主题：桌面底色带颜料晕染，创作流程每一步拥有专属色相（黛蓝、赭石、藤黄、朱砂、绛紫、石绿），卡片顶沿加笔触条；浅色与深色两套主题同步打磨。
- 情节大纲续写允许故事演进：提示词与逐章契约明确授权引入新角色（写明身份与作用）、把新地点/势力/规则写进世界观，并要求每章有推进主线的实质变化，避免同一小批角色贯穿全书；「大纲分批接力守卫」Skill 升至 1.1.0，内置提示词库升至 1.5.0。升级后旧的进行中检查点会按安全设计要求从最新断点重新起批，已确认章节继续作为前缀生效。

性能：

- 修复打开作品与回书房时的全库完整性扫描（成本随数据文件线性增长）：例行打开改为版本与指纹浅校验，深度校验保留给迁移路径。
- 修复生成期间「思考过程」分块的 O(n²) 重渲染：分块缓冲约 160ms 合并提交，单条文本封顶保留尾部，生成期间拖动窗口与界面响应恢复流畅。
- 草稿全量列表轻量化（跳过依赖稿正文哈希）并在打开期间合并重复请求；回书房概览的定稿收据核验增加缓存。
- 章节审稿/修稿事实改为主进程单次聚合返回，消除逐稿多次 IPC 往返。

## English

Version 1.6.0 is a product-level upgrade: global navigation and writing-flow redesign, a full-manuscript review center, a painterly theme, a launch animation, and a round of open/generation performance fixes.

New:

- Redesigned global navigation: the left rail gathers the library, the writing workspace (setup/architecture/blueprint/manuscript), full review, and AI runs, with direct entries to Models and Prompts; the Ctrl+K palette covers every destination.
- Full Review Center: a book-wide issue board aggregating each chapter's latest review, filterable by severity and status, with one-click jumps back to the chapter; the library home shows review to-dos.
- The writing flow expands to six steps: Setup → Architecture → Blueprint → Writing → Review → Finalize & export, each with live progress and its own hue.
- A launch animation: a seal-and-paper opening with a one-time transition into the library; skipped when reduced motion is requested.
- Library work-status cards for review to-dos and running AI tasks, shown only when there is something real to act on.
- The run sheet's "Recoverable work" section collapses to a single count row, remembered per book.

Improvements:

- Painterly theme: pigment-washed desktop background, a dedicated hue per flow step, brush-stroke accents on cards; both light and dark themes tuned.
- Plot-outline continuation now lets the story evolve: prompts and the per-chapter contract explicitly allow introducing new characters (with identity and role), extending the world, and require concrete main-line advancement each chapter; the Outline Continuation Guard skill is now 1.1.0 and the built-in prompt library 1.5.0. Existing in-flight checkpoints are re-batched from the latest frontier by design; accepted chapters keep working as the prefix.

Performance:

- The full-database integrity scan on every open and library return (linear in database size) is replaced by a shallow version/fingerprint check for routine opens; deep verification stays on the migration path.
- The O(n²) re-render of streaming "thinking" text is fixed: chunks are buffered (~160ms) and capped to a tail, so window dragging and UI response stay smooth while generating.
- The all-drafts listing is lightweight (no dependency-body hashing) and de-duplicated during open; the library overview caches finalized-receipt verification.
- Chapter review/revision facts are aggregated in one main-process call, removing per-draft IPC round trips.

Windows installers are unsigned. Mac installers are ad-hoc signed, with no Developer ID signature or Apple notarization.
