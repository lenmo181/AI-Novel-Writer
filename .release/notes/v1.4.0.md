# 1.4.0

## 中文

1.4.0 是面向长篇写作流程的一次完整升级，更新源已切换到 `lenmo181/AI-Novel-Writer`。

改进：

- 情节大纲支持按已设置的副篇章数自动连续生成，批次完成后自动接续，遇到可恢复的网络或服务暂时失败会有限重试，并保留当前断点。
- 写作 Skills 与提示词模板增加结构化的长篇规划、卷章衔接、角色连续性和审稿自检指导。
- 写作工作台加入更清晰的运行状态、进度反馈和轻量动态画面；支持减少动态效果偏好，窄屏布局保持可用。
- 应用内更新、官网入口和发布工作流统一使用本仓库的 GitHub Releases。
- 发布版本提供 Windows x64 安装包，并保留跨平台发布校验与完整更新元数据。

修复：

- 生成任务中断后恢复入口会绑定当前检查点，不再继续到过期批次。
- 更新检查和下载失败会保留可读错误原因，避免把原始服务错误直接显示到界面。

## English

Version 1.4.0 upgrades the long-form writing workflow and moves the official update source to `lenmo181/AI-Novel-Writer`.

Improvements:

- Plot outlines now continue through the configured number of sub-chapters automatically. Completed batches resume from the next checkpoint, and recoverable network or temporary service failures receive bounded retries.
- Writing Skills and prompt templates add structured guidance for long-form planning, volume and chapter continuity, character consistency, and review self-checks.
- The writing workspace has clearer run status, progress feedback, and restrained motion. Reduced-motion preferences are respected and narrow layouts remain usable.
- In-app updates, the official homepage, and release workflows now use this repository's GitHub Releases.
- The release provides a Windows x64 installer while retaining cross-platform release qualification and update metadata checks.

Fixes:

- Recovery actions bind to the current checkpoint instead of resuming an expired batch.
- Update check and download failures retain readable reasons without exposing raw provider errors to the renderer.

Windows installers are unsigned. Mac installers are ad-hoc signed, with no Developer ID signature or Apple notarization.
