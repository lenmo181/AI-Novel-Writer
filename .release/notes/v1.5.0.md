# 1.5.0

## 中文

1.5.0 为书房带来了 AI 封面与更主动的更新提醒，并把浅色主题整体打磨了一遍。

新增：

- 书架新增「AI 生成封面」：根据书名、类型与你的风格描述自动撰写生图提示词，由图像模型生成竖版封面，预览满意后一键使用；封面在书架卡片上铺图展示，可随时重新生成或移除。
- 发现新版本时全局弹窗提醒，展示该版本的更新内容，提供「稍后更新」与「立即更新」；立即更新在 Windows 上直接开始下载，macOS 上打开下载页。
- 每 1 小时自动检查一次新版本（原来只在启动时每天最多检查一次），发现新版本即弹窗提醒。
- 设置「关于与更新」页面下方新增「更新日志」，逐版本列出新增、改进与修复内容。

改进：

- 浅色主题全面优化：桌面与纸面层次更深，正文与小字墨阶更清晰，分隔线与阴影更利落，滚动条颜色随主题走。
- 修复两处首帧闪色：应用窗口底色跟随后动主题，启动加载页按已保存的外观主题取色，加载动画换成纸墨配色。
- 架构文档、提示词模板、模型表单、导入导出等旧组件的提示底色改走主题令牌；深色下强调色底的白字对比度修正。
- 修复 lint 基线：云端配置校验正则与工作流重试循环的历史告警。

## English

Version 1.5.0 adds AI cover art to the library and more proactive update notifications, and polishes the light theme throughout.

New:

- The bookshelf gains "AI cover": the app drafts an image prompt from the book title, genre, and your style notes, an image model renders a portrait cover, and you can keep it with one click. Covers fill the shelf card and can be regenerated or removed at any time.
- A global dialog now announces new versions with their release notes, offering "Later" and "Update now". Updating starts the download immediately on Windows and opens the download page on macOS.
- Update checks now run every hour (previously once per day at startup), and a dialog appears as soon as a new version is found.
- The About & updates page gains a changelog listing what each version added and fixed.

Improvements:

- The light theme is refined across the board: deeper desk-versus-paper layering, clearer text contrast, crisper separators and shadows, and theme-aware scrollbars.
- Two first-paint flashes are fixed: the window background now follows the saved theme, and the loading page reads the appearance profile with the paper-ink palette.
- Legacy surfaces (architecture docs, prompt templates, model forms, import/export) now use themed tokens; white-on-accent contrast in dark mode is corrected.
- Lint baseline fixes for a historical control-character regex and a retry loop.

Windows installers are unsigned. Mac installers are ad-hoc signed, with no Developer ID signature or Apple notarization.
